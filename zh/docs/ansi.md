# 查看 ANSI 着色文件

[English](../../docs/ansi.md) · **简体中文**

读完本页就能带颜色查看保存下来的终端输出，也能去掉转义码阅读；不需要任何设置。

## 为文件着色

语言为 `ansi` 的文件一打开就会着色。`.ans` 与 `.ansi` 文件自动生效，其他文件用 `files.associations` 映射：

```jsonc
{ "files.associations": { "*.log": "ansi" } }
```

这些文件会因此失去内置 `log` 语法的高亮，包括时间戳的颜色。内置 `log` 语法本来就会把转义码显示成乱码，所以文件里确实有转义码时，换成 ansi 更合适。只想临时给单个文件着色，就运行 **更改语言模式**（英文界面：Change Language Mode）并选 **ANSI Text**。

## 去掉转义码阅读

**Lang Toolkit: 在侧边打开 ANSI 预览**（英文界面：Open ANSI Preview to the Side）会打开一份去掉转义码、保留颜色的副本；编辑器标题栏的按钮效果相同，按住 Alt 点击则在当前编辑器打开。预览是普通的只读编辑器而不是 webview，搜索、选择、复制与并排滚动都照常可用，源文件改动时预览同步更新。

## 支持的颜色与样式

颜色映射到当前主题的 `terminal.ansi*` 调色板，因此与集成终端一致，并随主题切换。

- 颜色：16 种基本色（8 种常规色加 8 种亮色）、256 色（`38;5;n`）与 24 位真彩色（`38;2;r;g;b`），可用于文字、背景和下划线（`58;5;n`、`58;2;r;g;b` 及冒号写法）。
- 样式：粗体、弱化、斜体、下划线、双下划线（`21` 与 `4:2`）、删除线、上划线、反色与隐藏。
- 光标移动、清行等其他控制序列会淡化显示，而不是显示成乱码。进度条、spinner 与 `docker build` 的输出大部分由它们构成。

停止输入 300 ms 后重新着色。颜色组合特别多的文件见[故障排查](troubleshooting.md#已知限制)。
